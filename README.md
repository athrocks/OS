# Operating Systems Lab Programs

This repository contains a collection of Operating Systems (OS) lab programs and theory notes, implemented in C and shell scripting. These are designed for academic and practical understanding of key OS concepts such as process management, memory management, and file systems.

## Table of Contents

- [ALP Program](./ALP%20Program)
- [Classical Problems](./Classical%20Problems) – Solutions to classical synchronization problems like Producer-Consumer, Reader-Writer, Dining Philosophers.
- [Computing Time](./Computing%20Time) – Programs to calculate system and user execution time.
- [Deadlock](./Deadlock) – Deadlock detection and avoidance algorithms.
- [Disk Scheduling Algorithms](./Disk%20Scheduling%20Algorit...) – FCFS, SSTF, SCAN, C-SCAN, etc.
- [Matrix Operations](./Matrix%20Operations) – OS-relevant matrix operations.
- [Multi-Threading Theory](./Multi-Threading%20Theory) – Theoretical concepts of multithreading.
- [MultiThreading](./MultiThreading) – Practical implementation using `pthread`.
- [Page Replacement Algorithms](./Page%20Replacement%20Alg...) – FIFO, LRU, Optimal algorithms.
- [Read and Copy File Content](./Read%20and%20Copy%20File%20Con...) – Programs to demonstrate basic file handling.
- [ShellAdvanceProgram](./ShellAdvanceProgram) – Advanced shell scripting examples.
- [System Call](./System%20Call) – Demonstration of Linux system calls like `fork()`, `exec()`, `wait()`.
- [Zombie_Orphan](./Zombie_Orphan) – Understanding zombie and orphan processes.
- [shellScripting](./shellScripting) – Basic shell scripting exercises.
- [how to run Threaded Code](./how%20to%20run%20Threaded%20C...) – Instructions for compiling and running threaded C programs.

## How to Use

1. Clone the repository:
```bash
git clone https://github.com/athrocks/OS.git
cd OS
```

2. Navigate to any directory and compile the C programs:
```bash
gcc filename.c -o outputname -lpthread
./outputname
```

3. For shell scripts, provide execute permission and run:
```bash
chmod +x script.sh
./script.sh
```


Requirements

- GCC Compiler (for C programs)

- Bash (for shell scripts)

- Linux-based OS recommended for compatibility
